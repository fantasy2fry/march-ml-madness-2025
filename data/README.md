### Description of the data
- elo.csv: This file contains ELO for each team and their coach
for the moment just before the match! This file will be used to 
predict the outcome of the match during training i validation of the models.
Primary keys are Season, DayNum and TeamID
- final_elo_coach.csv: This file contains the final coach ELO (just before 2025 tournament) for each team and their coach 
- final_elo_team.csv: This file contains the final team ELO (just before 2025 tournament) for each team
